# brewargv

Brew timestamps and argv durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/brewargv/

## Install / run

```bash
git clone https://github.com/theworker02/brewargv.git
cd brewargv
node src/cli.js
node --test
```
